# StratFolio dark liquid dashboard mockup

- Use case: `ui-mockup`
- Asset type: high-fidelity desktop web app dashboard concept
- Generation mode: built-in image generation

## Prompt

Redesign the StratFolio AI investing portfolio dashboard with production-grade
consumer-finance polish. Use a charcoal-to-graphite dark gray foundation and a
distinctly blue liquid-glass visual language. The design should feel calm,
premium, trustworthy, approachable, and sophisticated—inspired by the ease and
emotional clarity of leading consumer trading apps without copying a branded
layout.

Show an edge-to-edge 16:10 desktop application viewport with no device frame. A
slim left navigation contains the exact wordmark "StratFolio" and the items
"Portfolio", "Positions", "AI Ideas", "News", "Planner", and "Activity". The
main area includes a compact top bar, headline portfolio balance, a prominent
blue performance chart, four concise metrics, an AI outlook panel, and a clean
holdings table. Use fewer, larger surfaces on a precise 12-column grid rather
than many floating cards.

Use realistic, shippable product UI—not concept art—with crisp sans-serif type
and accessibility-first contrast. Use near-black graphite `#0D1117`, dark slate
`#161C25` and `#202938`, liquid cobalt/electric blue `#2F7BFF` and `#5BA6FF`,
cool off-white text `#F4F7FB`, and muted steel text `#8D99A8`. Reserve green and
red for gains and losses. Materials are translucent smoked-glass panels with
subtle blue refraction, faint edge highlights, 18–24px radii, restrained blur,
and minimal shadows.

Prominent text: "StratFolio", "Portfolio value", "$248,392.18",
"+$2,418.73 (+0.98%) today", "AI Outlook", "Constructive", "Your Positions",
"Day P/L", "Total return", "Buying power", and "Concentration".

Constraints: production-feasible React web UI; readable typography and numbers;
no people, photos, device frame, or trademarks besides the original StratFolio
wordmark; no watermark. Avoid neon cyberpunk, purple-heavy gradients,
frosted-white cards, excessive glow, bubbly toy UI, giant empty hero areas,
tiny labels, clutter, 3D objects, and stock imagery.
